# FAQ

**Do I need BuddyPress?**
No. Without BuddyPress, every WordPress position and the shortcode work. Activity stream ads need BuddyPress with the Activity Streams component on.

**Does it work with BuddyBoss?**
Yes. Activity stream ads show in the BuddyBoss News Feed.

**Why does my ad code show as text?**
The person who last saved the ad cannot post unfiltered HTML, so script and style tags were removed. Ask an Administrator to save the ad.

**Can Editors manage ads?**
Yes. Anyone who can edit pages can create ads and switch them on or off. The plugin settings screen needs manage_options by default.

**Will switching an ad off and then editing it turn it back on?**
No. The Enable/Disable switch keeps its value when you update the ad.

**How often does an ad repeat in the activity stream?**
At entry N, set in Show After Entry. With Repeat on, at every Nth entry, including entries loaded with Load More.
