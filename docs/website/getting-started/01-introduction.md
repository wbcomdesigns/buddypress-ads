# Introduction

BuddyPress Ads lets you place ads on your WordPress site and inside BuddyPress activity streams. You can run ad-network code (AdSense, Amazon and similar), a rich-text promo built in the WordPress editor, or a simple image banner.

## What the plugin does

- Shows ads before or after post and page content, in the site header, or in the site footer.
- Shows ads inside BuddyPress activity streams (sitewide, group and member profile streams), every Nth entry.
- Gives every ad a shortcode, so you can place it in any post, page or widget.
- Limits each ad to logged-in members, logged-out visitors, mobile devices or desktops.
- Adds global header, body and footer code fields for verification tags and tracking scripts.

BuddyPress is optional. Without it, every WordPress position and the shortcode still work.

## Requirements

- WordPress 6.9 or later
- PHP 8.1 or later
- BuddyPress (optional) with the Activity Streams component on, for activity stream ads
