# Who Sees an Ad

The **To Whom** box on each ad limits who sees it. These rules apply to every placement, including the site header and the shortcode.

- **Logged-In Visitor**: show the ad to logged-in members, logged-out visitors, or both.
- **Device**: show the ad on mobile devices (tablets included), desktops, or both.

Device detection happens on the server. If your site uses a full-page cache, make sure it keeps separate mobile and desktop copies, or set the device to both.
