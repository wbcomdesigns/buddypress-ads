# Ad Types

## Plain Text and Code

Paste ad-network code, HTML or plain text. Script and style tags run as written, once per ad slot, including ads loaded into the activity stream by **Load More**.

Script and style tags are kept only when the person who last saved the ad can post unfiltered HTML (on a single site, Administrators and Editors). For anyone else, the tags are removed and the rest of the ad still shows.

Turn on **Allow Shortcodes** to run shortcodes inside the ad. With it off, a shortcode shows as plain text.

## Rich Content

Build the ad in the WordPress editor: text, links, images and shortcodes. Shortcodes always run in rich content ads. Use **Font Size** and the custom colors option to style it.

## Image Ad

Choose an image from the media library and set the link it opens. If the size fields are empty, choosing an image fills them with the image's own size. If you already typed a size, choosing or removing an image keeps it. When you set both width and height, the image keeps that size and crops to fit, and it scales down on narrow screens. The link opens in a new tab and is marked as sponsored for search engines. The ad title is used as the image alt text.
