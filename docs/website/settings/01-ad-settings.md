# Ad Settings

These options are on each ad under **WB Ads > Edit**.

## WB Ads Type

Plain Text and Code, Rich Content or Image Ad. See [Ad Types](../features/01-ad-types.md).

## Ads Parameter

| Option | What it does |
|---|---|
| Ad code (plain) | The code or text to show. |
| Allow Shortcodes (plain) | Runs shortcodes inside the ad code. |
| Editor (rich) | The ad content. |
| Font Size (rich) | Text size in pixels. |
| Use custom colors (rich) | Off: the ad uses the page's colors and follows the theme in light and dark mode. On: the background and text colors you pick are used everywhere. |
| Image, URL, Size (image) | The banner, the link it opens, and its width and height in pixels. A size you type is kept when you change the image. |
| Alignment | Left, center or right alignment of the ad. |
| Line break after the ad | Adds a line break after the ad so following content starts on its own line. |
| Margin | Space around the ad, in pixels, for each side. |

## Display Conditions

| Option | What it does |
|---|---|
| WordPress Position | None, before content, after content, site header or site footer. See [Where Ads Appear](../features/02-placements.md). |
| BuddyPress Activity Type | The activity streams the ad appears in. |
| BuddyPress Activity Position | The slot inside each activity entry. |
| Show After Entry | Entry number N. If you leave it empty or set it to 0, the ad shows every 3 entries. |
| Repeat | Show the ad every N entries instead of once. |

The BuddyPress options appear only when the Activity Streams component is on. When BuddyPress is active with Activity off, the box says so.

## To Whom

Logged-in visitor and device rules. See [Who Sees an Ad](../features/03-visibility.md).
